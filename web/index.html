CHIP-8

Instructions

Select a ROM using the options from the left. Different ROMs run best with different instructions per frame numbers; some are best at 10 IPF, others at 100IPF.

The emulator inputs are mapped to the keyboard, so use 1234 QWER ASDF ZXCV (a 4x4 grid on North American keyboards) to control it. Control schemes vary by ROM and it takes some playing to figure it out. For pong, it is 1/Q and 4/R to move the left and right paddles up and down, respectively

You can find ROMs around on the internet if you search for them, but I also found some and included them in the dropdown. Loading them from a link may or may not work, depending on the server's CORS policy (it doesn't work wit GitHub, for instance).
